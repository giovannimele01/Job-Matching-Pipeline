# Job Matcher Pipeline

A FastAPI service that analyzes a candidate's CV against a job description and
returns a structured match report: technical gaps, experience gaps, interest
alignment, and an LLM-generated narrative summary.

## Tech Stack

- **[FastAPI](https://fastapi.tiangolo.com/)** — HTTP API layer
- **[LangChain](https://www.langchain.com/)** + **[Google Gemini](https://ai.google.dev/)** (free tier, via `langchain-google-genai`) — structured extraction and narrative generation
- **[Pydantic](https://docs.pydantic.dev/)** — data validation and structured LLM output schemas
- **[SQLAlchemy](https://www.sqlalchemy.org/)** + **SQLite** — persistence (dev setup, no auth)
- **[pypdf](https://pypdf.readthedocs.io/)** / **[python-docx](https://python-docx.readthedocs.io/)** — text extraction from PDF/DOCX/TXT uploads

## Project Structure

```
requirements.txt
```

## Environment Variables

The app reads its configuration from a `.env` file in the project root (see
`app/config.py`). Create one with:

```
GOOGLE_API_KEY=your-google-gemini-api-key
GOOGLE_MODEL=gemini-3.5-flash
```

- `GOOGLE_API_KEY` — **required**. Get one from [Google AI Studio](https://aistudio.google.com/apikey).
- `GOOGLE_MODEL` — optional, defaults to `gemini-3.5-flash` (Gemini's current free-tier model).
- `DATABASE_URL` — optional, defaults to `sqlite:///./data/job_matcher.db`.

`.env` is git-ignored and must never be committed — it holds a real API key.

## Setup

### Option A: Local (venv)

1. Create a virtual environment and install dependencies:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Create `.env` as described above.
3. Run the server:
   ```
   uvicorn app.main:app --reload
   ```
4. Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) for the interactive API docs.

### Option B: Docker

1. Create `.env` as described above.
2. Build the image:
   ```
   docker build -t job-matcher .
   ```
3. Run the container, passing `.env` in at runtime (the API key is never baked
   into the image — it's read from the host's `.env` only when the container
   starts):
   ```
   docker run -d --rm --name job-matcher --env-file .env -p 8000:8000 job-matcher
   ```
4. Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) for the interactive API docs.
5. Stop it with:
   ```
   docker stop job-matcher
   ```

## API

- `GET /health` — service status and active model
- `POST /match` — upload a CV and a job description (`cv`, `job_desc` form fields, PDF/DOCX/TXT), returns a `MatchReport`:
  - `punteggio_match` — 0-100 compatibility score
  - `lacune_tecniche` — required skills missing from the CV
  - `lacune_esperienza` — experience gaps
  - `allineamento_interessi` — candidate interests aligned with the role
  - `prompt_finale` — narrative summary generated by the LLM
